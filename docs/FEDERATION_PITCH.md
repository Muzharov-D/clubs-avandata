# Clubs · Avandata — бизнес-кейс для федерации / лиги

> Стратегия **B** (регуляторная платформа данных): федерация — точка входа.
> Этот документ — то, чем заходим к федерации/лиге. Не про фичи — про надзор,
> подотчётность развития и контроль над потерей таланта в регионе.

---

## 1. Проблема, которой никто не владеет

Регион тратит годы и деньги на детский футбол — и **не знает, развивает он талант
или теряет его**. Сегодня у федерации нет инструмента ответить на простые вопросы:

- Какие клубы реально **развивают** игроков, а какие просто **числятся / побеждают**
  за счёт раннего физического созревания?
- **Где регион теряет талант?** Сколько способных детей не получают игрового
  времени и тихо уходят из футбола?
- Кому давать финансирование и аккредитацию — по результату на табло или по
  качеству развития?

Ответы сейчас — на глаз. Профессиональные системы (InStat, Wyscout) — про скаутинг
взрослых и дороги; управленческий софт (расписание, оплаты) — не про развитие.
**Между ними — пустота: подотчётность развития. Её и закрываем.**

## 2. Решение — «телескоп» над регионом + карта потерь

Единая платформа, где у каждого свой кабинет, но данные — общие:

- **Федерация** — телескоп: регион → клуб → команда → игрок. Одной метрикой
  прослеживается сверху вниз. Видно, кто развивает, кто теряет.
- **Спортивный директор / клуб** — развитие по возрастам, честность игрового
  времени, кадровый резерв, «требует внимания».
- **Тренер** — рейтинги, подготовка к матчу, состав.
- **Родитель** — прозрачность: играет ли ребёнок, развивается ли клуб.

**Клин — «Карта потерь».** Платформа считает то, что не считает никто в стране:
**эффект даты рождения (RAE)** и **монополию игрового времени**. Поздно рождённые
(Q3–Q4) системно недополучают минут и теряются — это измеримая утечка таланта.

> **Живой пример (Первенство СПб, реальные данные):** игрок 2011 г.р., рождён
> 27.12 (Q4), за турнир получил **~1% игрового времени (5 минут)**. Он «в заявке»,
> но фактически не играет. Платформа подсвечивает таких — десятки на регион.

## 3. Ценность для федерации

| Что получает федерация | Зачем |
|---|---|
| **Надзор за развитием**, а не только за результатами | финансирование/аккредитация по качеству, а не по табло |
| **Карта потерь таланта** по региону | вернуть в футбол детей, которых система отсеивает по дате рождения |
| **Объективный рейтинг клубов** | прозрачные, защищаемые решения вместо «по знакомству» |
| **Отчёты «на совещание»** в один клик | готовые материалы для минспорта/совета |
| **Региональные бенчмарки**, которых нет ни у кого | данные многих клубов вместе → картина, недоступная одиночке |

## 4. Почему это защищено (ров)

Ценность растёт с числом клубов: чем больше клубов в системе, тем точнее
региональные бенчмарки и рейтинги — **которых нет ни у одного клуба и ни у InStat**.
Федерация, посадившая клубы на платформу, становится **держателем уникального
слоя данных о таланте региона**. Это сетевой эффект: повторить дорого, обойти нельзя.

## 5. Как это работает на практике

1. Федерация даёт платформе мандат (рекомендует/обязывает клубы вести данные).
2. Клубы получают кабинеты: **база — бесплатно**, глубина/бенчмарки/минуты — платно.
3. Данные клубов агрегируются → федерация видит регион целиком.
4. Родители получают прозрачность → спрос снизу подтягивает клубы.

Источник данных — **официальный API Первенства** (протоколы, минуты, составы):
ничего не надо вводить руками, платформа подхватывает то, что уже есть.

## 6. Что просим — пилот

**Пилот на 5–10 клубах одного дивизиона, 1 сезон.** Федерация получает телескоп +
карту потерь по этим клубам. Критерий успеха: федерация принимает ≥1 решение
(финансирование / аккредитация / адресная работа с клубом) **на основе данных
платформы**, а не интуиции.

Технически готовы: кабинеты 4 ролей, рейтинги, карта потерь и телескоп работают на
реальных данных клуба-флагмана уже сегодня.

## 7. Почему сейчас

- Официальные данные Первенства уже доступны по API — техническое окно открыто.
- Тема «не теряем детей» резонирует с повесткой минспорта/федераций.
- Первый, кто посадит регион на слой данных о таланте, закрепит категорию за собой.
