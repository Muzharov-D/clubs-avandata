# CIES Football Observatory — методика профилирования (наш референс)

Источник: CIES Monthly Report n°81 (Scouting report: promising U21 talents).
Берём методику; **отбрасываем** трансферную стоимость, рыночную цену, возрастной пик
(контекст — детско-юношеский футбол, не профи).

## 1. Восемь игровых областей (отпечаток активности игрока)

CIES раскладывает игру на **8 областей** (domains) с конкретными переменными:

| # | Область (CIES) | Переменные | Наш русский ярлык |
|---|---|---|---|
| 1 | Air defence | воздушные единоборства в обороне | Воздух — оборона |
| 2 | Ground defence | наземные единоборства в обороне | Отбор внизу |
| 3 | Recovery | подборы + перехваты | Возврат мяча |
| 4 | Distribution | передачи (объём/точность) | Распасовка |
| 5 | Take on | кроссы + удачные обводки | Обыгрыш |
| 6 | Chance creation | ключевые передачи + ассисты | Созидание |
| 7 | Shooting | удары | Завершение |
| 8 | Air attack | воздушные единоборства в атаке | Воздух — атака |

Каждая область нормируется (на 90 мин) и переводится в **перцентиль против игроков
той же позиции**. Это и есть «отпечаток» — заменяет наши плоские группы атака/защита/физо.

## 2. Двадцать категорий игроков (позиция + доминирующие области)

«Архетип» по CIES = позиция × где у игрока главная вовлечённость:

- **Вратарь** — все вратари
- **ЦЗ оборонительный** / **ЦЗ-распасовщик** (низкая/высокая вовлечённость в распас)
- Кр.защ: **оборонительный** / **универсальный (two-way)** / **атакующий** (лев/прав)
- ОПЗ: **опорник оборонительный** / **опорный плеймейкер** / **универсальный ЦПЗ** /
  **атакующий плеймейкер** / **атакующий ЦПЗ**
- Вингеры: **бьющий** / **универсальный** (лев/прав)
- Форварды: **бьющий ЦФД** / **универсальный ЦФД**

→ Обогащает наш `archetypeOf()` в PlayerDnaCard: вместо «Финишёр/Креативщик» —
позиционно-корректные категории, по-русски, словами для тренера.

## 3. «Капитал опыта» (experience capital)

CIES: playing time × уровень соревнования × результаты.
**Наш юношеский аналог:** минуты/матчи на своём возрасте + стабильность роли +
тренд формы. Без трансферной стоимости.

## Как ляжет на нас

1. **Отпечаток профиля** (PizzaChart/SeasonProfileCard) → 8 областей CIES с
   позиционными весами. Данные у нас уже есть в pizza-шаблонах (under-метрики
   attack/defence/fitness) — нужна перегруппировка по 8 областям.
2. **Архетип ДНК** (`PlayerDnaCard.archetypeOf`) → 20 категорий CIES (по-русски).
3. **Перцентиль vs позиционный пул** — у нас уже есть (vs команда), уточнить ярлык.
4. **Командный отчёт «ДНК команды»** — стиль игры по осям (отдельный фреймворк
   CIES «Style of play of teams»: владение прямой↔комбинационный, высота прессинга/
   PPDA, вертикальность, фланги, стандарты, линия обороны).

## ОБНОВЛЕНИЕ из PDF «Rapport Scouting 2025» (U20, версия декабря 2025)

Более точная и свежая версия — её и реализуем:

**Профиль игрока = 6 областей-активности как КОЭФФИЦИЕНТ к среднему по выборке:**
1. Воздух (jeu aérien) · 2. Возврат (récupération) · 3. Распасовка (distribution) ·
4. Обыгрыш/продвижение (percussion) · 5. Созидание (assistance) · 6. Завершение (finition).
**Значение >1 = выше среднего, <1 = ниже.** Это лучше «сырого перцентиля»: тренер
сразу видит, где игрок над/под средним. (У нас: считать активность на 90 мин,
делить на среднее по позиционному пулу → коэффициент.)

**Ранжирование (если нужен общий скор) = 8 областей** с весом по уровню турнира +
«капитал опыта» (минуты в официальных взрослых матчах × уровень). **Вратари — только
капитал опыта**, без игровых областей.

**15 категорий 2025** (позиция × доминирующие области), русские ярлыки:
- Вратарь
- ЦЗ: **боец** (ball-fighting) / **универсал** (well-rounded) / **распасовщик** (ball-playing)
- Фланг.защ: **цепкий** (ball-chasing) / **универсал** / **подключающийся** (forward-pushing)
- ОПЗ/ЦПЗ: **разрушитель** (ball-winning) / **дирижёр** (playmaking) / **универсал** / **атакующий** (forward-oriented)
- Вингер: **врывающийся** (infiltrating) / **универсал**
- Форвард: **столб/воздушный** (aerial) / **универсал** (well-rounded)

Карточка игрока CIES: возраст · клуб · нога · минуты · 6-осевой профиль-коэффициент.
