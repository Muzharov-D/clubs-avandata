# Глоссарий показателей

Утверждён руководством 1 октября 2026. Источник истины в коде — `backend/src/federation/metricsGlossary.ts`:
интерфейс берёт названия и описания **только** оттуда.

Правила:
- технические названия событий разметки («Передача +» и т. п.) в интерфейсе **не показываются никогда**;
  над каждым показателем — маленький «?» с описанием из этого глоссария;
- методика расчёта (веса событий, формула рейтинга) **нигде и никогда** не указывается — ни в интерфейсе,
  ни в подсказках, ни в выгрузках;
- все показатели считаются **за полный матч своего возраста**: U14 — 60′, U15–U16 — 70′, U17–U18 — 80′.
  Минуты на поле — по заменам в разметке матча (без перерыва). В сравнение со сверстниками попадают
  игроки с 45+ минутами за сезон.

## Завершение
| Показатель | Что это |
|---|---|
| Голы | Забитый мяч. |
| Удары в створ | Удар, который шёл в створ ворот (включая голы). |
| Удары мимо | Удар, который не попал в створ: мимо ворот или в блок. |
| Удары (в профиле) | Все удары — в створ и мимо. |

## Созидание
| Показатель | Что это |
|---|---|
| Созданные голевые моменты | Игрок создал голевой момент для команды любым действием: передачей, обводкой, выходом. |
| Прогрессивные передачи | Точная передача, которая продвигает мяч к воротам соперника. |
| Успешные обводки | Обыграл соперника один в один и сохранил мяч. |
| Подачи угловых | Подача углового удара. |

## Владение
| Показатель | Что это |
|---|---|
| Сохранение мяча под прессингом | Удержал мяч, когда на него давил соперник. |
| Потери под прессингом | Потерял мяч под давлением соперника. Чем меньше, тем лучше. |
| Неточные передачи | Передача, после которой мяч ушёл сопернику. Чем меньше, тем лучше. |
| Неудачные обводки | Попытка обводки, после которой мяч потерян. Чем меньше, тем лучше. |
| Игра под прессингом (в профиле) | Доля удержанных мячей под давлением: сохранения против потерь. |
| Надёжность передач (в профиле) | Доля удачных передач: прогрессивные против неточных. |

## Оборона
| Показатель | Что это |
|---|---|
| Отборы | Отобрал мяч у соперника в единоборстве. |
| Перехваты | Перехватил передачу соперника. |
| Прессинг | Надавил на соперника с мячом и вынудил его ошибиться. |
| Контрпрессинг | Сразу надавил на соперника после потери мяча командой. |
| Выносы | Выбил мяч из опасной зоны у своих ворот. |
| Блоки в штрафной | Заблокировал удар или передачу в своей штрафной площади. |

## Ошибки (чем меньше, тем лучше)
| Показатель | Что это |
|---|---|
| Сорванные голевые атаки | Испортил развитие голевой атаки своей команды. |
| Упущенные голевые моменты | Испортил создание голевого момента в атаке своей команды. |
| Упущенная опека | Упустил своего игрока в обороне. |
| Позиционные ошибки | Неверно занял позицию, и соперник этим воспользовался. |
| Грубые ошибки | Ошибка, после которой у соперника гол или верный голевой момент. |
| Автоголы | Мяч, забитый в свои ворота. |
| Офсайды | Положение «вне игры». |
| Фолы | Нарушение правил. |
| Жёлтые / красные карточки | Предупреждение / удаление. |

## Вратарь
| Показатель | Что это |
|---|---|
| Простые / средние / трудные / невероятные сейвы | Отражённый удар по сложности. |
| Ошибки вратаря | Ошибка вратаря, после которой у соперника был момент или гол. |
| Пропущенные голы по вине вратаря | Пропущенный гол, ответственность за который на вратаре (только для вратарей). |

## Технические события
Выход на поле, замена, перестановка — в показатели не входят, используются только для подсчёта минут на поле.

## Специализации (утверждено 1 октября 2026, обновлено: полузащита объединена, сторона не важна)
Источник в коде — `backend/src/federation/positionGroups.ts` (специализации для сравнения) и
`frontend/src/routes/holding/viz.tsx` (`lineup`, `toSlots` — расстановка на доске). В справочнике
AvanData 21 позиция; системные коды местами не совпадают с названиями, поэтому сопоставляем только по названию.

| Специализация (с кем сравнивается) | Позиции AvanData | Места на доске (4-3-3) |
|---|---|---|
| Вратари | Вратарь | Вратарь |
| Центральные защитники | Левый / правый центральный защитник, центральный защитник | Два места в центре защиты |
| Крайние защитники | Левый / правый защитник, левый / правый фулбек | Два места на флангах защиты |
| Центральные полузащитники | Опорный (любой стороны), атакующий (левый / правый / центральный) | Опорная зона + два места в центре |
| Крайние нападающие | Левый / правый нападающий, левый / правый полузащитник | Два места на флангах атаки |
| Центральные нападающие | Центральный, левый / правый центральный нападающий | Центральный нападающий |

Индекс сезона, перцентили, «к амплуа лиги», ДНК и ролевой профиль считаются внутри специализации.
Сторону (левый/правый) аналитики часто ставят по умолчанию, поэтому правого не сравниваем отдельно с правым.

**Доска комплектования.** Основа каждой команды собирается по специализациям: сначала своя
специализация (лучшие по индексу), недостающее место закрывает тот, кого туда ставит тренер, затем —
кто реально выходил на этой позиции. Фланг — по тому, где игрок чаще выходил. В опорную зону встаёт
центральный полузащитник, сильнее всех в игре в обороне (перцентиль очков за оборонительные действия
среди своей специализации).

**Позиции тренера.** В профиле игрока руководство может добавить позицию, на которой его хочет видеть
тренер (таблица `holding_player_positions`). Доска учитывает её в первую очередь и показывает игрока в
глубине этой позиции с жёлтой пунктирной меткой.
