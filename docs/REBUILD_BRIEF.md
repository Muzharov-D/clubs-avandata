## 2. Доступ к данным (это РАБОТАЕТ, переиспользовать)
- **API-база разборов: `https://back.avandata.ru`**, авторизация заголовком
  **`X-API-Key`** (ключ владельца «Ключ для Федерации» `sd_0909…`, лежит локально в
  `backend/.env` как `AVANDATA_API_KEY`; на Render env он ТОЖЕ задан — прод работает).
  `app.avandata.ru` — это SPA, НЕ API.
- Полная карта API базы — **`docs/AVANDATA_API_MAP.md`** (54 ресурса, NestJS REST,
  пагинация `{data,meta}`). Ключевое:
  - `/ffspb-portal/getSeasonsList` → сезоны→турниры(возрасты U13–U18, dateBirthFrom)→дивизионы(Высшая/Первая).
  - `/ffspb-portal/overview/{season}/{ffspbStatistics|getTeamsRatings}/{overview|tournamentId}` — таблицы/рейтинги клубов (сезон или по возрасту).
  - `/ffspb-portal/matches/getListMatches?tournamentId&divisionId&tour` — матчи (счёт `ownTeam.score`, `status`, `ffspbMatchId`).
  - `/ffspb-portal/players/by-role?...` — игроки тура (id, имя, dateOfBirth=ГОД, позиция, команда, averageRating).
  - `/players/{id}` — ПОЛНАЯ дата рождения. `/player-summaries` (4628, полная дата, пагинация).
  - `/events?mainPlayerId={id}&limit≤100` — события игрока (37 метрик). `/event-types` — каталог метрик с очками + категория attack/defense.
- **Прокси-слой уже написан и РАБОТАЕТ** (переиспользовать, НЕ выкидывать):
  `backend/src/services/avandataApi.ts` (клиент по ключу) + `backend/src/federation/avandataSource.ts`
  (трансформация + TTL-кэш) + роуты `backend/src/federation/routes.ts` (`/api/v1/federation/av/*`).
  Эндпоинты: `overview, results, standings, club-ratings, division-strength, players, players/:id,
  tournaments, compare, years, age-effect, concentration, cohorts`.

## 3. Подводные камни данных (выстрадано, не наступать снова)
- **`tourStatistics.analyzedMatches` ВРЁТ (=0)** — детектить разобранное по факту, что
  `getPlayersByRole` вернул игроков. Иначе было 151 игрок вместо 977.
- **`lastPlayedTour` ненадёжен** (равен числу туров; последний тур часто несыгран).
- **Сыгранный матч = `status==='ready'` И счёт>0** (свежие матчи имеют несинканный 0:0 — показывать нельзя).
- **Название команды содержит ГОД** («ФК Зенит 2012»). Реальный клуб = срезать год (`clubName`).
- **ID-пространства разные**: `by-role.id`/`/players/{id}` ≠ `/player-summaries.id` (связь — `player-summary-players`).
- RAE считается по полной дате из `/player-summaries`.

## 4. Что в данных РЕАЛЬНО есть (богатство — на чём строить)
- 977 разобранных игроков (рейтинг/позиция/клуб), **4628** в реестре с полной датой.
- **249 159 событий** (per-player 37 метрик). 26k расстановок (on-field, минуты).
- Таблицы + рейтинги клубов AvanData по дивизионам и возрастам. Реальные результаты матчей.
- AI-разборы матчей (`/ai-reports`, gpt-5.4). Видео матчей. Тренеры. Привязка к FFSPB.
- **Реальные находки:** RAE-перекос Q1/Q4 ≈ ×2 (регион отсеивает поздно-рождённых,
  по когортам ×1.57…×2.4); монополия (топ-3 клуба = 33% таланта, Зенит лидер);
  пропасть лиг (Высшая ≈ ×2 Первой по рейтингу).

## 5. Что хочет федерация (подтверждено владельцем — 4 СУПЕРСУТЕВЫХ вопроса)
1. **Кто наши лучшие + кто восходит** (скаутинг-борд; знаменатель есть только у федерации).
2. **Справедлива ли система / кого теряем** (RAE/возможность/утечка — диагноз).
3. **Какие клубы сильнее / кто производит талант** (рейтинг школ, производство).
4. **Как идут турниры (результаты/таблицы)** (операционка).
- **ГЛАВНЫЙ экран = «Состояние региона» (клубы/турниры)** — операционная картина,
  которую функционер открывает первой.
