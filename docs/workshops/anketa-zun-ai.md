_2026-06-04 · анонимная · для Google Forms_

**Цель:** понять уровень и запросы аудитории, чтобы со второй встречи давать
**разноуровневый контент** (отдельные треки для новичков и продвинутых).

**Вступление для формы (вставить в описание):**
> Анкета анонимная — имя и почту не спрашиваем. Отвечай честно: цель не оценить
> тебя, а собрать группы по уровню и подобрать материал, который не будет ни
> скучным, ни слишком сложным. 3–5 минут.

> ⚙️ В Google Forms: **выключи** сбор email (Настройки → Ответы → «Собирать
> email-адреса» = выкл), включи «Показывать индикатор прогресса». Тип вопроса
> указан в `[квадратных скобках]` — в форме его НЕ пишем.

### Как из ответов собрать разноуровневые треки
- **Вопросы 3, 4, 5, 6** → уровень. Грубое правило:
  - **Трек A (старт):** «не пробовал/пробовал пару раз» + уровень «Новичок/Базовый» + ≤2 отметки в в.5.
  - **Трек B (рост):** «уверенный/продвинутый» + есть опыт инструментов + 3–6 отметок в в.5.
  - **Трек C (про):** «эксперт» / Claude Code/Cursor в в.6 / умеет «собрать прототип».
- **Вопросы 7, 8** → темы и реальные кейсы для практики.
- **Вопросы 9, 10, 11** → темп, формат и нагрузка по группам.
- **Вопросы 12–14** → что чинить в подаче (та самая «скука» части аудитории).
