## 1. ЭТАЛОН-РЕЗЮМЕ (дизайн-язык клубного фронта на один экран)

**Палитра — 6-ступенчатая глубина (ключ к «дорого»):**
`--bg-page #0a0c10` → `--bg-page-2 #0e1117` → `--bg-surface #141821` →
`--bg-surface-2 #1b212c` → `--bg-surface-3 #232b38`; границы `--border #262d3a` /
`--border-strong #343d4e`. Текст 4 уровня WCAG-AA: `--text #f3f6fc` /
`--text-muted #97a3b6` / `--text-muted-strong #b4c0d2` / `--text-faint #828fa6`.

**Тени тинтованы в сине-чёрный + хайлайт-кромка (НЕ чистый #000):**
`--shadow: 0 2px 6px rgba(6,11,22,.4), 0 12px 32px -8px rgba(6,11,22,.5)`;
`--shadow-lg: 0 8px 24px …, 0 24px 64px -16px …`; `--ring: 0 0 0 1px rgba(255,255,255,.04)`.
Каждая карта несёт `box-shadow: var(--shadow), var(--ring)`.

**Карточка — не плоская заливка, а вертикальный градиент-свет:**
`background: linear-gradient(180deg, color-mix(in srgb,var(--bg-surface) 92%,#fff 3%), var(--bg-surface))`;
ховер = `border-color: --border-strong` + `--shadow-lg` (подъём тенью, БЕЗ translate).

**Типографика:** тело — **Inter** (15px, lh 1.5); все крупные числа/счёт/рейтинги —
**Space Grotesk** (`--font-display`) всегда с `font-variant-numeric: tabular-nums`.
Заголовки трекинг `-0.02em`; секц-лейблы uppercase `+0.08em`.

**Семантическая шкала рейтинга (носитель смысла, не бренд):**
`--rating-excellent #4caf50` · `good #82bc47` · `ok #fbc02d` · `weak #fb8c00` ·
`poor #ef4444` · `none #888` (0/null = серый «—», `utils/colors.js → ratingColor`).

**Фон приложения:** два CSS radial-glow по углам из бренд-цвета (7–12%),
`background-attachment: fixed` — без растровых картинок.

**Секц-заголовок:** `.page-section-title` 12px uppercase + фирменная **акцент-риска
`::before` 3×13px** бренд-цвета. Лейблы конкретные («Матчи», «Запасные»), не поэтичные.

**Ритм страницы (един для всех экранов эталона):** один «герой» во всю ширину →
(плотные экраны) якорная под-навигация `md-secnav` → стопка карточек-секций, каждая =
один вопрос → переключатели периода/метрики табами → у каждой секции **микро-сноска-
инструкция чтения** (факт, не поэзия).

**Моушн:** карточки СТАТИЧНЫ по умолчанию. Из движения — только `:active scale(.97)`
на кнопках, ховер-подъём тенью, однократное наполнение баров (`hsc-grow`/`width .6s`).
Killswitch `html.fx-off` + `prefers-reduced-motion` guard.

**BEM-вокабуляр компонентов-доноров:** `donut-card__*`, `hero-next__*`, `leader-card__*`,
`rating-pill--xl`, `best-player__*`, `match-detail__*`, `splits-table`, `cd__*`,
`club-overview__*`. Сетки именованы под смысл, не под число колонок.
