# Редизайн интерфейса — план

**Направление:** премиальная тёмная аналитика (ориентир Opta / StatsBomb / Linear-dark).
**Подход:** сначала страница-эталон (Разбор матча), утверждаем язык → раскатываем на всё.
**Правило:** меняем визуал, НЕ ломаем функционал. Пицца игрока — не трогаем без запроса.

---

## Этап 0 — Дизайн-токены (фундамент, без визуальных сюрпризов)
Переписываем `frontend/src/styles/index.css` `:root` как настоящую систему:
- **Типографика:** подключить премиальный шрифт (заголовки/цифры — напр. «Geist» или
  «Space Grotesk» для дисплея + «Inter» для тела; цифры — `tabular-nums`). Сейчас
  голый system-ui — отсюда «пресно».
- **Шкала размеров и веса** (модульная, контраст ≥1.25), **спейсинг-шкала** (4-base),
  радиусы, **многослойные тени** (ambient + key), elevation-уровни поверхностей.
- **Цвет:** тёмная база глубже, акцент выразительнее; точечное стекло/блюр; токены
  под состояния (hover/active/selected/focus).
- **Моушн-токены:** длительности (120/200/320), ease-out-expo, stagger-шаг.
Итог: токены готовы, старые компоненты пока выглядят почти так же — но дальше всё
тянется из них.

## Этап 1 — Эталонная страница: Разбор матча (MatchDetail) ← ЗАВТРА
Полный визуальный апгрейд одной страницы как референс «как должно быть»:
- **Hero матча** — переосмыслить: крупный счёт, гербы, дата, плашка достоверности
  как премиальный бейдж; глубина и акцент.
- **Карточки/секции** — единый ритм, новые тени/радиусы, воздух, заголовки секций
  с новой типографикой.
- **Графики** (beeswarm / scatter / half-split / heatmap / зоны) — подвести под
  новый визуальный язык: цвета из токенов, аккуратные подписи, премиальные ховеры
  и тултипы.
- **Моушн:** появление секций со stagger при скролле (IntersectionObserver),
  плавные переходы, «живые» бары/точки. Всё с `prefers-reduced-motion`.
- **Навигация по разделам** — сделать выразительной (активное состояние, прогресс).
Результат: страница, на которую смотришь и говоришь «вау». Утверждаем язык.

## Этап 2 — Общие компоненты (раскатка языка)
Переводим на новый язык переиспользуемое (меняется везде сразу):
`.card`, `.page-section-title`, `RatingPill`, `RatingCard`, кнопки/инпуты,
`SidebarNav`, `AppHeader`, `Toast`, `EmptyState`, `Skeleton`, `DataQualityBadge`,
`StatCompareBar`, `DonutComparisonCard`.

## Этап 3 — Остальные страницы
По одной, в стиле эталона: Дашборд клуба → Профиль игрока → Рейтинг/Сравнение/
Нагрузка → Матчи → Календарь → Админка/Логин. Каждая — отдельный PR, CI зелёный.

## Этап 4 — Полировка и консистентность
Сквозной проход: контраст (WCAG AA), адаптив/мобайл, тач-таргеты, единые состояния,
финальный `/impeccable polish` + `detect`. Прогон `/impeccable critique` ключевых
страниц до высокого скоринга.

---

## Процесс
- Каждый этап — ветка + PR + зелёный CI + мерж (как сейчас).
- После Этапа 1 — пауза на утверждение визуального языка.
- Вдохновение: пользователь соберёт примеры топ-сервисов → уточняем направление
  перед Этапом 2 (раскаткой), чтобы язык был «тот самый».
- Проверка вживую через браузер на `clubs-avandata.vercel.app` (домен
  `clubs.avandata.ru` сейчас с битым SSL — инфраструктура, чинится отдельно).
