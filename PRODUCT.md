# PRODUCT.md — Clubs · Avandata

**Register:** product (app UI / dashboard / analytics tool — design SERVES the data, not the other way around).

## Что это
Мульти-тенантная SaaS-платформа футбольной аналитики для клубов (`clubs.avandata.ru`).
Тренер загружает PDF/Excel-отчёты SportVisor по матчу → получает разбор: рейтинги
игроков, командные показатели, тепловые карты, динамику по таймам, физнагрузку.

## Кто и где пользуется (scene)
Тренер академии (ФК «Зенит» / СШОР) на ноутбуке в раздевалке или дома вечером
после матча, при искусственном свете, в рабочем фокусе. Смотрит плотные данные,
сравнивает игроков, готовит разбор команде. → **тёмная тема оправдана**
(данные читаются долго, тёмный фон снижает усталость и делает цветные акценты
графиков заметнее). Не «тёмная, потому что модно».

## Аудитория
- `head_coach` / `team_coach` — основные пользователи (разбор, рейтинги, нагрузка).
- `player` — видит только свой профиль.
- `platform_admin` — управление клубами (отдельная админка).
- `parent` — публичные path-based экраны без auth (расписание).

## Color strategy: **Restrained**
Тинтованные нейтрали (тёмная база `--bg-page`/`--bg-surface`) + один бренд-акцент
(cyan/blue тенанта, ≤10% поверхности). Бренд клуба задаётся в `tenants.brand` JSONB
и пишется в CSS-переменные через `applyTheme()` при login. Семантика данных
(лучше/хуже соперника, шкала рейтинга «отлично→плохо») — отдельная функциональная
палитра (green/amber/red), НЕ бренд. Цвет несёт смысл, не украшает.

## Типографика
- `--font-display`: Space Grotesk — заголовки, крупные числа/рейтинги (tabular-nums).
- `--font`: Inter — тело.
- Контраст через scale + weight, не через много шрифтов.

## Принципы (что делает этот продукт «не AI-slop»)
1. **Число спокойное, смысл — в обрамлении.** KPI-значения единым near-white;
   «лучше/хуже» читается рамкой/тинтом/delta-чипом, не перекраской цифры.
2. **Данные плотные, но дышат.** Вертикальный ритм между секциями; внутри — сетки с gap.
3. **Доступность не опциональна.** WCAG AA контраст, focus-visible, prefers-reduced-motion,
   tabular-nums на всех числах в таблицах/сравнениях.
4. **Моушн осмысленный.** Вход блоков (витрина), count-up чисел, ease-out. Без bounce.
5. **Токены, не хардкод.** Цвета/радиусы/длительности из CSS-переменных.

## Анти-паттерны для этого проекта (Absolute bans skill применимы)
- Боковые цветные грани >1px (side-stripe) на карточках — заменять полной рамкой/тинтом.
- Gradient-text (background-clip:text) — сплошной цвет.
- Декоративный glassmorphism без цели.
- Хардкод hex вместо токенов.

## Стек (контекст)
React 19 + Vite + TanStack Query + React Router 7. Mix legacy `.jsx` + новые `.tsx`.
Деплой: Vercel (FE, авто из main) + Render (BE). CI-гейт (tsc+build) на каждом PR.
